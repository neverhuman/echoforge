# EchoForge Jankurai Standard

This repository follows the root `AGENTS.md` and the Jankurai bootstrap files
under `agent/`.

- Strict-open core.
- Radar-first product scope.
- Public-proxy signatures only unless lawful measured data is explicitly
  labeled.
- Keep generated outputs, solver results, and large artifacts out of Git.
- Use the smallest credible proof lane for a change.
