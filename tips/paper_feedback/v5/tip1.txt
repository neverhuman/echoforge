```tex
\begin{abstract}
EchoForge is a strict-open synthetic benchmark for low-altitude uncrewed aerial system (UAS) radar and multimodal sensing research. Strict-open means that assumptions, code, configuration, detector-view schemas, and paper evidence are reviewable from public or generated sources, while generated arrays and measured raw files remain outside Git. The paper-facing positive class is a fixed-wing pusher-prop public proxy with explicit uncertainty; it is not a measured-platform claim and is not a fielded-sensor surrogate. EchoForge combines a radar signal-chain model card, acoustic and passive-RF cue definitions, group-locked scenario splitting, detector-view feature denylisting, hard-negative false-alarm analysis, compare-only measured-anchor checks, and holdout-isolated evaluation into a reproducible evidence package. The v2 single-seed run contains 10,000 scenario groups, 50 positive groups, and 30,000 phase records. On the 4,500-record blind holdout, with 24 positive records from eight positive scenario groups, the engineered intelligence (EI) candidate reaches point Recall@$\leq$1\%FPR of 0.833 and LCB95 Recall@$\leq$1\%FPR of 0.699; the prior fusion baseline reaches 0.292 and 0.083, respectively. EI improves average precision, selected-threshold false-positive control, and low-FPR recall for this synthetic public-proxy benchmark, while its ROC AUC is lower than the prior fusion baseline. These results should be read as reproducible benchmark evidence under declared assumptions, not as measured truth, named-platform equivalence, or operational performance.
\end{abstract}
```

```python
def _style_axes(ax: Any, *, xgrid: bool = False, ygrid: bool = False) -> None:
    if xgrid:
        ax.xaxis.grid(True, color=GRID, linewidth=0.7)
    if ygrid:
        ax.yaxis.grid(True, color=GRID, linewidth=0.7)
    ax.set_axisbelow(True)
    for spine in ("top", "right"):
        ax.spines[spine].set_visible(False)
    ax.spines["left"].set_color(GRID)
    ax.spines["bottom"].set_color(GRID)
    ax.tick_params(colors=MUTED, labelsize=7.2)


def _clean_label(value: Any, width: int = 22) -> str:
    return _wrap(str(value).replace("locked candidate", EI_SHORT), width)


def _signed_color(value: float, vmax: float) -> str:
    if not math.isfinite(value):
        return "#F7F7F2"
    norm = TwoSlopeNorm(vmin=-vmax, vcenter=0.0, vmax=vmax)
    return NIGHT_RG(norm(value))


def _annotate_bars(ax: Any, bars: Any, *, fmt: str = "{:.3f}", dy: float = 0.015) -> None:
    for bar in bars:
        value = float(bar.get_height())
        ax.text(
            bar.get_x() + bar.get_width() / 2,
            min(value + dy, ax.get_ylim()[1] * 0.98),
            fmt.format(value),
            ha="center",
            va="bottom",
            fontsize=6.7,
            color=INK,
        )


def _horizontal_value_labels(ax: Any, values: list[float], y_positions: Any, *, fmt: str = "{:.3f}") -> None:
    xmax = ax.get_xlim()[1]
    for value, ypos in zip(values, y_positions):
        if not math.isfinite(value):
            continue
        ax.text(
            min(value + xmax * 0.015, xmax * 0.98),
            ypos,
            fmt.format(value),
            va="center",
            ha="left",
            fontsize=6.8,
            color=MUTED,
        )
```

```python
def validate_dimensions() -> None:
    if Image is None:
        print("visual validation warning: Pillow unavailable; skipped dimension checks")
        return

    bad = []
    for name, (min_w, min_h) in MIN_DIMENSIONS.items():
        path = FIGURES_DIR / name
        with Image.open(path) as im:
            width, height = im.size
        if width < min_w or height < min_h:
            bad.append(f"{name}={width}x{height}, expected at least {min_w}x{min_h}")

    if bad:
        fail("undersized figure(s): " + "; ".join(bad))
```

## Appendix upgrade

The current fixed-wing appendix already says no measured Iranian-drone radar signature, no operational route/evasion modeling, no payload-effects inference, no deployment-performance claim, and no sensor-parity/classified-fidelity claim.  That is good, but it is too thin for a tier-1 paper. Add an explicit appendix suite:

```tex
\appendices

\section{Source and Assumption Ledger}

\subsection{Fixed-Wing Pusher-Prop Public Proxy}
The positive class is a fixed-wing pusher-prop public proxy. It is motivated by open visual reporting and public summaries of fixed-wing pusher-prop UAS geometry, but EchoForge does not use measured Iranian-drone radar signatures, recovered hardware measurements, proprietary sensor returns, or classified performance information. The proxy includes only broad geometry, speed, launch-phase, RCS-envelope, and prop-cadence assumptions.

\subsection{Noise, Clutter, and RFI Assumptions}
EchoForge models clutter and impairment pressure through declared synthetic priors: Weibull/K-like clutter envelopes, sea/terrain/weather stress, AGC compression, clock drift, quantization, dropped CPIs, PRF ambiguity, Doppler folding, calibration offset, multipath masking, and RFI bursts. These are stressors for detector comparison, not calibrated field-rate claims.

\subsection{Detector Archetype Assumptions}
The X/Ku, S-band, GBAD, acoustic, passive-RF, and fusion branches are detector-view archetypes. Public systems and public radar literature bound the role envelope, but the benchmark does not reproduce vendor processing, ECCM, classified sensitivity, exact Pd/Pfa, operator workflow, emitter libraries, or deployment topology.

\subsection{Workflow and Algorithm Summary}
At a high level, EchoForge samples scenario strata, expands each scenario group into phase-locked records, synthesizes public-proxy radar/acoustic/passive-RF cues, materializes detector-facing views under a feature denylist, fits/calibrates candidates only on train/CV rows, writes a selection lock, scores the blind holdout once, and emits a paper evidence bundle. The repository intentionally exposes enough configuration and evidence for audit while not publishing generated raw arrays or measured raw traces.

\subsection{Generative-Origin Self-Classification}
The generative-origin audit is a manifest-based self-classification of tracked source lines of code. It is not proof of authorship history. Report the generated values from \texttt{generative\_origin\_audit.json}: generative/AI-inspired LOC, human-standard LOC, percentage generative LOC, and percentage human-standard LOC.
```

The repo already has a generative-origin manifest that explicitly frames the audit as a self-classification, not authorship proof, and it defines generative/AI-inspired versus human-standard categories. Use those generated percentages rather than hand-entering them.
