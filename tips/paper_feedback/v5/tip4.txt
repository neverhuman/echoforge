def _pretty_method_label(value: Any, width: int = 20) -> str:
    raw = str(value or "")
    label = METHOD_LABELS.get(raw, raw.replace("_", " "))
    return "\n".join(
        textwrap.wrap(label, width=width, break_long_words=False, break_on_hyphens=False)
    )


def _metric_color(delta: float) -> Any:
    delta = _safe_float(delta, 0.0)
    return NIGHT_RED_GREEN(DELTA_NORM(delta))


def _style_axis(ax: Any, *, grid: str = "x") -> None:
    if "x" in grid:
        ax.xaxis.grid(True, color=GRID, linewidth=0.7)
    if "y" in grid:
        ax.yaxis.grid(True, color=GRID, linewidth=0.7)
    ax.set_axisbelow(True)
    for spine in ("top", "right"):
        ax.spines[spine].set_visible(False)
    ax.spines["left"].set_color(GRID)
    ax.spines["bottom"].set_color(GRID)

## Appendix changes

The current paper has useful appendix material, but it is not rich enough for a tier-1 review package. It mentions the fixed-wing pusher-prop public-proxy appendix and prohibited inferences, including no measured Iranian-drone radar signature, no operational route/evasion modeling, and no payload-effects inference, but it needs a stronger source/config/workflow appendix. 

Add these sections before `Limitations and Prohibited Inferences`:

```tex
\section{Source, Noise, and Detector Configuration Appendix}

\subsection{Public-source assumptions and prohibited source transfer}
The fixed-wing pusher-prop public proxy is built from open visual reporting and public summaries only. The Iranian-drone source pack is used only for approximate public geometry, public flight-envelope priors, and broad pusher-prop observables. It is not a measured Iranian-drone radar signature, not an operational route model, not an evasion model, and not a payload-effects model. KTH, Open Radar, RAD-DAR/RDRD, and related public radar collections remain compare-only anchors for observable-shape checks; they do not create positive-class truth.

\subsection{Noise, clutter, and receiver assumptions}
The synthetic impairment stack includes Weibull/K-like clutter, sea/terrain/weather stress, AGC compression, clock drift, quantization, dropped CPI, PRF ambiguity, Doppler folding, calibration offset, multipath masking, and RFI burst regimes. Acoustic cues are node-wise spectral cadence, cross-node agreement, and amplitude stability. Passive-RF cues are no-signal behavior, RFI bursts, clock-offset stress, and provenance-quality geometry.

\subsection{Detector/source configuration cards}
The detector cards separate detector-visible products from excluded truth fields. X/Ku, S-band, GBAD, acoustic, passive-RF, and fusion cards define public-source role envelopes and detector-facing features only; proprietary sensitivity, ECCM, vendor processing, operator workflows, emitter libraries, payload commands, and deployment topology are excluded.

\section{Engineered-Intelligence Workflow Appendix}
The EI workflow is summarized at a high level. Detector-view tables enter train/CV-only candidate discovery after split keys, labels, scenario-group identifiers, and hidden generator metadata are denied to the model-facing schema. Candidate families are explored on train/CV rows, sparse nonnegative fusion weights are selected, a monotone geodesic-odds calibration is fit, and the selected lock freezes candidate ID, weights, calibrator, and threshold before any blind-holdout score is read. The blind holdout is then scored once, and group-block bootstrap intervals, false-alarm-family diagnostics, calibration bins, and component summaries are emitted into the evidence bundle. This description exposes the algorithmic workflow needed for review without disclosing implementation internals or raw search traces.

\section{Generative-Origin Audit Appendix}
The evidence bundle includes a manifest-based source-line audit that self-classifies tracked paper-lane files into human-standard and generative/AI-inspired categories. This is an auditable self-classification of source LOC, not proof of authorship history. The paper should report the generated percentages from \texttt{generative\_origin\_audit.json}: human-standard LOC, generative/AI-inspired LOC, total classified LOC, percentage human-standard LOC, and percentage generative/AI-inspired LOC.
```

The repo already has a generative-origin manifest and audit machinery that self-classifies tracked LOC; it explicitly frames this as an auditable self-classification, not proof of authorship history.
