## Highest-priority diagnosis

The current paper does **not** have a content-only problem. It has a production-quality figure-system problem.

The renderer currently builds several figures around 10 inches wide or 7.6 inches wide, then LaTeX scales them into IEEE two-column or one-column slots. That destroys text size. The phase figure’s “strange lines” are not confidence intervals: the code currently plots `selected_recall` as red horizontal line segments over the selected AP bars in `figure_phase_kpi`, which is visually ambiguous and should be removed. 

The current visual validator is also too weak: it checks required PNG/PDF presence and byte-size thresholds, but it does not verify rendered pixel dimensions, figure scale, or banned visible phrases like “locked candidate” / “selected AP.” 

The TeX still uses `\author{EchoForge Project}` and the abstract/paper language still says “locked candidate,” while the requested paper-facing identity is **NeverHumqn Research Group**, with **Jeppson Taylor** as lead author, and the model should be called **engineered intelligence (EI)**.

            min(value + 0.018, ax.get_ylim()[1] * 0.97),
            fmt.format(value),
            ha="center",
            va="bottom",
            fontsize=fontsize,

```python
def _generative_origin_percentage_rows(manifest_path: Path) -> list[dict[str, Any]]:
    manifest = _read_json(manifest_path)
    entries = manifest.get("files", []) if isinstance(manifest, dict) else []
    buckets: dict[str, dict[str, Any]] = defaultdict(lambda: {"files": 0, "non_empty_loc": 0})
    total_loc = 0

    for entry in entries:
        rel_path = str(entry.get("path", ""))
        if not rel_path:
            continue
        origin = str(entry.get("origin", entry.get("classification", "unknown"))).lower().replace(" ", "_")
        if origin not in {"human", "generative", "generative_assisted", "mixed", "unknown"}:
            origin = "unknown"

        path = REPO_ROOT / rel_path
        loc = _count_non_empty_lines(path) if path.exists() else _safe_int(entry.get("non_empty_loc"), 0)

        buckets[origin]["files"] += 1
        buckets[origin]["non_empty_loc"] += loc
        total_loc += loc

    rows: list[dict[str, Any]] = []
    for origin in ("human", "generative", "generative_assisted", "mixed", "unknown"):
        loc = int(buckets[origin]["non_empty_loc"])
        files = int(buckets[origin]["files"])
        rows.append({
            "origin": origin,
            "files": files,
            "non_empty_loc": loc,
            "pct_non_empty_loc": float((loc / total_loc) * 100.0) if total_loc else 0.0,
            "basis": "manifest-based self-classification; not authorship proof",
        })
    return rows
```
