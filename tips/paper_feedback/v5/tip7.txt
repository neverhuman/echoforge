## Highest-priority diagnosis

The current abstract and body still foreground “locked candidate,” with the author shown as “EchoForge Project.” The abstract claims the 0.833 point Recall@≤1%FPR and 0.699 LCB95 result, but it needs to say **Engineered Intelligence (EI)** and tighten the claim to “better low-FPR benchmark behavior,” not broad detector dominance. 

The strange lines in **Fig. 4** are not random rendering artifacts. They are the selected candidate’s Recall@≤1%FPR plotted as red horizontal ticks on top of AP bars. That makes the left panel visually ambiguous because the bars are AP while the red ticks are recall, and the legend only says baseline AP / selected AP. The fix is to delete the tick overlay entirely and use four explicit bars per phase: baseline AP, baseline R@≤1%FPR, EI AP, and EI R@≤1%FPR. The current Fig. 4 page shows exactly why this is confusing. 

The paper also needs a richer appendix. The existing fixed-wing pusher-prop appendix says there is no measured Iranian-drone radar signature, no operational route/evasion modeling, no payload-effects inference, and no deployment-performance claim, but it is too thin for a tier-1 review surface.  The limitations already admit the small holdout, single seed, simplified radar physics, lack of HIL evidence, and no measured positive validation; those caveats should remain, but the appendix should make the source/noise/detector assumptions auditable rather than merely defensive.

### 3. Replace the abstract

Use this replacement:

```tex
\begin{abstract}
EchoForge is a strict-open synthetic sensing benchmark for low-altitude uncrewed aerial-system (UAS) radar and multimodal detection research. Strict-open means that assumptions, code, configuration, detector-view schemas, and paper evidence are reviewable from public or generated sources, while generated arrays and measured raw files remain outside Git. The paper-facing positive class is a fixed-wing pusher-prop public proxy with explicit uncertainty, not a measured-platform claim. EchoForge contributes a radar-first signal-chain model card, acoustic and passive-RF cue definitions, group-locked scenario splitting, detector-view feature denylisting, hard-negative false-alarm analysis, compare-only measured-anchor checks, and holdout-isolated evaluation. In the v2 single-seed run, 10,000 scenario groups produce 30,000 phase records, with 50 positive groups total. On the 4,500-record blind holdout, containing 24 positive records from eight positive scenario groups, the Engineered Intelligence (EI) candidate reaches point Recall@$\leq$1\%FPR of 0.833 and LCB95 Recall@$\leq$1\%FPR of 0.699; the prior fusion baseline reaches 0.292 and 0.083. EI improves AP and low-FPR recall while its ROC AUC is lower than the prior fusion baseline, so the claim is better low-FPR benchmark behavior rather than universal rank dominance. These results are synthetic public-proxy evidence under declared assumptions, not measured truth or operational performance claims.
\end{abstract}
```

That preserves the strong headline result while avoiding an overclaim. This is especially important because the paper itself reports only 24 positive holdout records from eight positive scenario groups.

```python
def _style_axis(ax: Any, *, grid_axis: str = "x", title_size: float = 9.2) -> None:
    ax.set_facecolor(PANEL_BG)
    if grid_axis in ("x", "both"):
        ax.xaxis.grid(True, color=GRID_LIGHT, linewidth=0.7)
    if grid_axis in ("y", "both"):
        ax.yaxis.grid(True, color=GRID_LIGHT, linewidth=0.7)

    for spine in ("top", "right"):

    ax.title.set_weight("bold")
    ax.title.set_color(TEXT)


def _delta_color(value: float, *, scale: float = 0.75) -> tuple[float, float, float, float]:
    if not math.isfinite(value):
        return (0.8, 0.8, 0.8, 1.0)
    normalized = 0.5 + 0.5 * max(-1.0, min(1.0, value / scale))
    return DELTA_CMAP(normalized)


def _metric_shade(value: float, *, vmin: float = 0.0, vmax: float = 1.0) -> tuple[float, float, float, float]:
    if not math.isfinite(value):
        return (0.95, 0.95, 0.95, 1.0)
    normalized = max(0.0, min(1.0, (value - vmin) / max(vmax - vmin, 1e-9)))
    return NIGHT_RED_GREEN(normalized)
```

## Figure-by-figure repair list

**Fig. 1 — architecture stack.** Keep the idea, but rename it “EchoForge radar evidence stack,” use the new EI-independent style helpers, and make the model-card snapshot a real card with consistent box widths. This figure is not broken, but it looks like a slide more than a tier-1 paper diagram.

**Fig. 2 — scenario balance/leakage.** Change `figure_monte_carlo_split_flow` to `figsize=(11.0, 6.6)` and `constrained_layout=True`. The title and panel labels currently collide, and the bottom footnote sits too close to axes. Use `FAMILY_CMAP` for bar colors, one consistent x-axis label “Scenario groups,” and move the audit sentence into a single bottom note.

**Fig. 3 — KPI/supporting diagnostics.** Use `EI candidate`, not `Locked candidate` or `selected`. The AP ranking label text is too small, the ROC/PR legends interfere with the data, and calibration bin labels are unreadable. Set calibration x-ticks to bin lower edges like `0.0, 0.1, …, 0.9`, not rotated `0.0-0.1` strings. The figure should still preserve the point result, LCB95 result, AP diagnostic, low-FPR ROC, PR curve, and calibration counts. 

**Fig. 4 — phase behavior.** Replace the misleading recall tick overlay with explicit grouped bars. This is the highest-priority visual fix. 

**Fig. 5 — EI components.** Rename the figure to “Engineered Intelligence components and comparable holdout deltas.” Use `EI nonnegative fusion weight` on the left axis, and color delta bars with the red-white-green diverging colormap. The current figure is conceptually useful, but labels are too cramped and the `selected` language is wrong. The companion Table IX is important because passive-RF-only has higher AP and fixed-FPR recall than full EI but worse F1/ECE; the paper should keep that guardrail. 

**Fig. 6 — radar model card.** Keep it, but enlarge table font to at least 7.4, scale rows to 1.30, and show receiver impairments in a two-column card rather than cramped mini-text. The current figure exposes the right facts but still reads like a packed poster. 

**Fig. 7 — range-Doppler proxy.** Use the same `NIGHT_RED_GREEN` colormap family, larger panel labels, and one shared colorbar. Keep it raster if needed, but force high resolution and consistent axis labels.

**Fig. 8 — anchor overlay.** Do not call the file or visible title `locked_algorithm`. Rename the visible title to “Compare-only measured-anchor overlay.” Ideally rename the output files from `locked_algorithm.png/pdf` to `compare_only_anchor_overlay.png/pdf`, then update `VECTOR_FIGURES`, `REQUIRED_FIGURES`, `generate_all`, and the TeX `\includegraphics`.
