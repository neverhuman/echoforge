- Timestamp: `20260518T113009Z`

## Why

The Monte-Carlo demo defaulted to a single Iranian-named preset
(`iranian-takeoff-v1`, target_label `"Iranian Public-Proxy Fixed-Wing
UAV Takeoff"`, ctor `MonteCarloDemoConfig::iranian_takeoff_default`).
This violated the user's "non-Iranian options" ask and the cross-tip
consensus (tip4/5/6/7) that neutral object IDs are mandatory for a
publishable open-source dataset. Country/system aliases now live only
in `object-packs/public-proxy-v1/source_dossier.yaml` per tip5's
`policy: source_dossier_only` convention.

## Notes

- The deprecated `iranian_takeoff_default(...)` shim intentionally
  routes to the neutral preset rather than preserving the old
  preset's identity — the OLD preset id no longer exists in the
  config library, so preserving it would have required keeping a
  parallel object class in the config. Cleaner to just deprecate the
  name.
- Backwards compatibility window: one minor release. Callers that
  pin to `iranian_takeoff_default` get a deprecation warning today;
  the symbol can be removed at v0.3.0.
