# solver-adapter-contract — formal SolverAdapter trait + solver_card schema surface

## Files Changed

- `schemas/solver_card.schema.json` — **additive only** schema bump.
  Added five new optional properties at the top level (none added to
  the `required` array, so back-compat with v1 solver_card fixtures
  is preserved):
  - `license_class` (enum `core_open | optional_open | restricted_plugin`)
    per FUCKIT.md.done P3 cross-tip resolution.
  - `capabilities` (object): `frequency_range_hz` (numeric_range ref),
    `solves_pec`, `solves_dielectric`, `solves_layered_dielectric`,
    `solves_anisotropy`, `solves_bistatic`, `solves_monostatic`,
    `supports_far_field`, `supports_near_field`,
    `max_electrical_size_lambda` (number, minimum 0),
    `parallelism_class` (enum `single_core | multi_core | gpu | distributed`).
  - `inputs` (object): `requires_mesh`, `requires_material_card`,
    `requires_polarization`, `frequency_sampling`
    (enum `user_specified | adaptive`).
  - `outputs` (object): `produces_rcs_cube`, `produces_currents`,
    `produces_near_field_volume`.
  - `convergence` (object): `produces_richardson_estimate`,
    `produces_cross_solver_delta`.
  Each new object uses `additionalProperties: false` so unrecognized
  sub-keys are caught early.
- **NEW** `crates/echoforge-solver-contract/Cargo.toml` — workspace
  member; depends on `echoforge-core` (for `NumericRange`), `serde`,
  `serde_json`, `thiserror`. No dev-dependencies needed (all tests are
  inline `#[cfg(test)]` and use `serde_json` from the main deps).
- **NEW** `crates/echoforge-solver-contract/src/lib.rs` — contract crate
  defining `SolverAdapter` trait + supporting value types:
  - `SolverAdapter` trait with `name`, `version`, `license_class`,
    `capabilities`, `plan`, `run`.
  - `LicenseClass` (snake_case serde enum: CoreOpen, OptionalOpen,
    RestrictedPlugin).
  - `ParallelismClass`, `FrequencySampling` enums (snake_case serde).
  - `Polarization` enum (UPPERCASE serde) re-defined locally to avoid
    dragging in the science-stack `echoforge-validate` dep.
  - `SolverCapabilities`, `SolverInputs`, `SolverOutputs`,
    `SolverConvergence` (`Option<_>` everywhere with
    `skip_serializing_if`, mirroring the schema's optional surface so
    canonical JSON output stays minimal).
  - `SolverPlanRequest`, `SolverPlan`, `SolverRunReport`, `RunStatus`.
  - `SolverError` (`thiserror`) with five variants: `Unsupported`,
    `InvalidRequest`, `InvalidPlan`, `Runtime`, `Internal`.
  - `NullSolver` struct + `Default` + `with_identity` constructor.
    `NullSolver` returns `LicenseClass::CoreOpen` and
    `Err(SolverError::Unsupported)` from both `plan` and `run` so it
    can serve as a placeholder/registry default and as a stable target
    for test scaffolding.
- `Cargo.toml` — added `crates/echoforge-solver-contract` to the
  workspace `members` array (single-line additive change between
  `echoforge-core` and `echoforge-studio`).
- `Cargo.lock` — `cargo` regenerated the lockfile to add the new
  `echoforge-solver-contract` package entry. No version bumps to any
  other dependency.
- **NEW** `.agents/receipts/solver-adapter-contract/20260518T123444Z.md`
  — this receipt.

Scope: schema-only additive bump + brand-new contract crate at
`crates/echoforge-solver-contract/`. No existing crate touched beyond
the workspace `members` line. The future `sagittasbr-adapter` packet
will land in its own crate and `impl SolverAdapter for SagittaSbr`

  workspace Cargo.toml" boundary.
- The new schema fields are intentionally **additive and
  un-mirrored** in `crates/echoforge-core::models::SolverCard` so the
  canonical SolverCard SHA-256 stays byte-stable for the
  contracts-smoke golden test. The next packet that lands a real
  adapter (`sagittasbr-adapter`) will likely want to extend the Rust
  struct with matching `Option<_>` fields and re-seed the golden;
  out of scope for this packet.
- `license_class` enum was intentionally kept at three variants
  (`core_open | optional_open | restricted_plugin`) matching the
  FUCKIT.md.done P3 cross-tip resolution and the wording in the
  packet brief. The strict-open default packaging treats absence as
  "unknown" rather than implicitly assigning `core_open`.
- `NullSolver` always reports `LicenseClass::CoreOpen`. Rationale:
  it is a no-op stub that ships with the strict-open default and
  carries no upstream license obligations.
- `Polarization` is re-defined locally rather than imported from
  `echoforge-validate` to keep the contract crate dependency-light
  and free of the science stack (validate pulls in `ndarray` /
  `num-complex`). Wire form (`UPPERCASE` H/V/L/R) matches the
  schema's `supported_polarizations` enum.
- The contract intentionally does NOT define a registry or loader.
  Adapter registration (static and dynamic) is left for the
  `sagittasbr-adapter` packet so the registry surface can be designed
  against a real adapter and a real loader at the same time.
- `SolverError::Unsupported` is the dedicated "try another solver"
  signal so a planner can fan out across registered adapters without
  having to disambiguate failure reasons.
