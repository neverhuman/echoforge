## Notes / Risks / Follow-ups
- The canonical `mesh_manifest` schema envelope (`provenance` / `license` / `validation`) was intentionally left to the caller; only the lightweight per-file `<primitive>_manifest.json` is emitted by `emit_mesh_bundle`. The full envelope composition belongs to the pipeline that ingests these meshes for the V-tier cross-check, since it owns the `public_proxy_id` selection and validation tier.
- No CLI subcommand was added; the FUCKIT directive flagged `crates/echoforge-cli/src/demo.rs` as actively edited by another worker, so the CLI surface is intentionally deferred to a follow-up packet. All functionality is reachable via the `echoforge-world` library API (`mesh::sphere_mesh`, `mesh::write_stl`, `mesh::emit_mesh_bundle`, etc.).
- `rtk just fast`, `rtk just contracts`, and `rtk node tools/vendor_scrub.mjs` cannot run green right now due to unrelated in-flight changes (Codex work on `echoforge-core::ValidationInfo` adding a `fidelity_class` field; Codex work on `echoforge-dataset::DatasetError::Yaml`; placeholder banlist entries). These were broken at HEAD before this packet started, and this packet did not touch any of those areas.
- No external mesh dependency added; only `sha2 = "0.10"` (already a workspace-pinned version, used by `echoforge-core` and `echoforge-dataset`).
- The trihedral plate normals follow the convention that each plate faces the interior of the +octant where the three plates meet, consistent with the Ruck-handbook trihedral-corner-reflector geometry expected by `echoforge-validate::primitives::trihedral`.
- Binary STL was chosen over ASCII for compactness and determinism; the 80-byte header carries a human-readable generator tag for debugging.
