## Notes
- Zero new runtime npm dependencies — Canvas 2D, WebGL-free rendering, and `useSyncExternalStore` keep the "hooks only, no store library" rule.
- The range-Doppler heat map uses Canvas-2D `putImageData` upscaling rather than WebGL; the grid is small enough (<=256x256) that this holds frame rate without shader code.
- Node 20 is required for the Vite 8 toolchain (`.nvmrc` pins 20); the ambient Node 18 cannot run the build.
- `apps/web/playwright-report/` is generated output and is intentionally not committed.
- Commit was created per explicit maintainer direction after scoped validation (pre-existing repo-wide `cargo fmt --all --check` failure is unrelated to this work).
