# Python Radar Primitives Quarantine

- Timestamp: `20260518T122352Z`
- Packet: `python-radar-primitives-quarantine` (FUCKIT.md roadmap)
- Slice: stack-discipline cleanup; remove duplicated Rust functionality
  from the Python tree per `AGENTS.md` "Stack discipline".

## Why

`python/ai-service/echoforge_radar/primitives.py` reimplemented an LFM
chirp generator, a matched filter, and CA-CFAR in pure Python. Per
`AGENTS.md`:

> Python is reserved for deep-science cross-checks (Mie series scipy
> oracle, validators that need scipy/numpy). All product, control-plane,
> and tooling code lives in Rust or TypeScript.

LFM chirp / CFAR are radar product primitives — already implemented in
the Rust crate `echoforge-radar` (`crates/echoforge-radar/`). The
Python copy is a stack-rule violation and a drift hazard, so this
packet quarantines it by deletion.

The legitimate `python/ai-service/echoforge_validate/` Mie scipy
oracle is untouched — it is the protected "deep-science cross-check"
the rule explicitly allows.
