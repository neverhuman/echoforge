**Scope:** Extend `TargetKinematics` with native per-class variants for

Shahed-class targets; gate the new multi-class dispatch with a
correctness test.

## Background

Wave 4 Lane I introduced `synthesize_scene(SceneDescriptor, …)` with
`TargetKinematics::FromTakeoffProfile(TakeoffProfile)` as the only
honoured kinematics case. Confuser classes (Bird, GroundVehicle,
WindTurbine, etc.) were still synthesised by
`echoforge-dataset::ml_training::build_frame_products` — a separate
envelope-statistics generator outside the unified chain. The
bifurcation meant the generator identity literally labelled the class.

Lane J promotes confuser kinematics to first-class
[`TargetKinematics`] variants and extends `synthesize_scene` to
dispatch N entities through the same IQ-accumulation chain that
positive targets traverse.

## Per-class `state_at` logic

A new `pub fn state_at(&self, t_s, initial_range_m, antenna_alt_agl_m)
-> TargetState` impl on `TargetKinematics` dispatches each variant:

- **FromTakeoffProfile**: delegates to `profile.state_at(t_s)`
  (byte-stable with pre-Lane-J back-compat path).
- **Bird**: straight-line geometry along `heading_deg` from
  `initial_range_m`; `radial_velocity_mps = cruise_speed_mps *
  cos(heading_rad)` (positive = closing).
- **GroundVehicle**: straight-line along `heading_deg` from
  `initial_range_m`; altitude pinned to 0 m AGL.
- **WindTurbine**: static; `range_m = hub_range_m`,
  `altitude_m = hub_altitude_agl_m`, `radial_velocity_mps = 0`.
- **MultipathGhost**: **panics** when called directly. Multipath
  geometry resolution happens at the `synthesize_scene` level via the
  `resolve_entity_state` helper, which looks up the parent's state
  and applies the `2·h_r·h_t/R` range offset (Skolnik 3rd ed. §1.6).
- **Balloon**: `tethered = true` → static; `tethered = false` → slow
  drift along `drift_heading_deg` at `drift_speed_mps`.
- **Kite**: stationary at `anchor_range_m`, with a deterministic
  0.5 Hz sinusoidal flutter on `radial_velocity_mps` bounded by
  `wind_gust_amplitude_mps`.
- **Helicopter**: same straight-line geometry as Bird; the
  dual-rotor micro-Doppler line spectrum is downstream of
  `state_at` via [`crate::micro_doppler_gen::HelicopterRotorGenerator`].

## Multi-entity synthesis dispatch

`synthesize_scene` in `crates/echoforge-radar/src/sim.rs` was
refactored to:

1. Compute a per-entity link-budget pass over each entity's initial
   state, producing `per_target_snr_db` (one entry per scene entity).
   `TargetClass::MultipathGhost` ghosts inherit the parent's SNR
   scaled by `20·log10(|Γ|)`.
2. For each pulse, iterate over `scene.targets`, dispatching
   `kinematics.state_at(t_s, …)` for each non-ghost entity and
   `resolve_entity_state` (parent geometry + range offset) for ghosts.
3. Accumulate each entity's per-pulse return into a shared IQ buffer.
   The scintillation draw order matches the legacy single-entity
   synth so pre-Lane-J reproduction fixtures replay byte-identically:
   the first entity's scintillation draw is the *first* RNG draw of
   the pulse, exactly as before.
4. Apply stochastic noise terms (clutter, AWGN, RFI, phase walk) in
   the same per-bin RNG order as the legacy synth.

A new field `SyntheticEpisode::per_target_snr_db: Vec<f64>` carries
the per-entity emergent SNR; the legacy `diagnostic_snr_db` field
holds the first entity's SNR for back-compat.

A first-order RCS proxy (`class_default_rcs_scalar`) selects the
linear RCS scalar per class using dossier-cited median dBsm values:
Bird = -25 dBsm, GroundVehicle = +5 dBsm, WindTurbine = +25 dBsm,
Balloon = -20 dBsm, Kite = -25 dBsm, Helicopter = +5 dBsm,
MultipathGhost / TerrainGlint / ManRadarReturn = -30 dBsm.
`FromTakeoffProfile` entities use their explicit `profile.rcs_scalar`
so the byte-stable Shahed path is preserved.

Full per-class RCS-aspect lookup against
`crate::rcs::Rcs::seeded_public_proxy_v1` and per-class propulsion
micro-Doppler modelling at the per-pulse amplitude surface remain
downstream Lane K scope. At the synthesis surface, confuser entities
get a unit micro-Doppler envelope (1.0) — a conservative first-order
proxy that does not over-claim confuser micro-Doppler fidelity.

## Multipath ghost geometry test result

The closed-form two-ray multipath range offset at `R = 10 000 m`,
`h_r = 20 m`, `h_t = 100 m` is:

```
R_ghost = R + 2·h_r·h_t/R = 10000 + 2·20·100/10000 = 10000.4 m
```

Verified bit-exact by the `multipath_ghost_range_offset` test
(`crates/echoforge-radar/src/scene.rs::tests`). The test also gates
the serde round-trip of the
`TargetKinematics::MultipathGhost { parent_idx, reflection_coefficient_magnitude }`
variant.
