## What was built

The headline credibility artifact for CFAR threshold integrity: a Monte-Carlo
calibrator that, for each `(ClutterRegime, CfarVariant)` tuple, generates
target-free clutter cells, slides a CFAR window across them, counts
false-alarm exceedances, and compares observed vs nominal Pfa via a 95%
Wilson confidence interval.

Lane G_a closed the **analytical** loop (OS-CFAR no longer silently borrows
the CA Gaussian alpha; Rohling-1983 closed form + 12-row ALPHA_LIBRARY
landed). Lane G_b closes the **empirical** loop: it actually counts the
false alarms produced by the existing alpha tables under the existing
clutter samplers, and gates them against their nominal design Pfa.

## Recipe to run the full 10^7 calibration

```bash
# Release build is essential; debug takes ~30x longer.
cd <repo-root>
rtk cargo test -p echoforge-radar --release --test empirical_pfa \
  -- --ignored --nocapture
```

Or via the CLI subcommand (writes a JSONL receipt for downstream tooling):

```bash
rtk cargo run --release --bin ef -- \
  calibrate empirical-pfa \
  --trials 10000000 \
  --seed 12648001 \
  --out "outputs/empirical_pfa/$(date -u +%Y%m%dT%H%M%SZ).jsonl"
```

Exit code is 0 when every nominal Pfa lies inside its observed 95% Wilson CI,
1 when any combo fails. Stderr prints `wrote N observations ... (X pass / Y fail)`.

## Known calibration gaps (the credibility evidence)

A 200k-trial smoke (`/tmp/empirical_pfa_200k.jsonl`) confirms the
calibrator's wiring and exposes which combos the existing
`cfar_alpha::resolve_alpha` actually nails vs. which fall back to
the 100k-trial Monte-Carlo fallback with a generic seed. Headline:

- **Gaussian / Rayleigh + CA-CFAR**: PASS (observed/nominal ~ 0.92x at
  200k trials). The Skolnik chap. 7.7.2 closed form holds.
- **Gaussian / Rayleigh + OS-CFAR(k=18, N=24)**: PASS (observed/nominal ~ 0.92x).
  The Rohling-1983 bisection alpha holds.
- **Gaussian / Rayleigh + GO/SO-CFAR**: FAIL (~1.7x / ~3.1x observed/nominal).
  `cfar_alpha` has no closed-form for these; the 100k-trial MC fallback at a
  fixed seed is not tight enough at 200k validation trials. Expected.
- **Weibull / K / log-normal**: mostly FAIL across CA/OS/GO/SO with
  observed/nominal ratios from 0.0x (alpha too pessimistic, threshold
  unreachable) to ~3.2x (alpha too optimistic). Expected: the
  ALPHA_LIBRARY has 12 rows; the standard 32-cell table spans configurations
  not in those rows, so `resolve_alpha` falls through to the same
  100k-trial MC fallback.

These results are themselves the credibility evidence — they tell a radar
engineer exactly where the existing alpha tables need expansion to clear the
C12 gate. The calibrator does not patch them; it surfaces them.

## Strict-open posture

Every reported `observed_pfa` is a simulator-internal Monte-Carlo measurement
of the existing CFAR alpha tables against the existing clutter samplers. No
measured-truth claim is implied; the calibrator's job is to verify that the
two halves of the pipeline are internally self-consistent under the synthetic
distributions they were derived for. Out-of-CI failures indicate either
(a) an alpha-table row needs to be added or (b) a sampler convention differs
from what the alpha was calibrated on (e.g. amplitude vs. power; see
`empirical_pfa::clutter_to_noise` for the bridge). No mitigation is applied
within this lane.

## Determinism

- Per-cell amplitudes are drawn from `SplitMix64` seeded by
  `seed ^ (cell_idx * 0x9e37_79b9_7f4a_7c15)`.
- Per-combo seeds are `master_seed ^ (combo_idx * 0x1234_5678_90AB_CDEF)`.
- Both XOR/wrapping-mul scrambles avoid trivial collisions and produce
  bit-stable output for a given `(master_seed, trials)` pair, verified by
  `measure_pfa_deterministic_for_fixed_seed`.

## Out of scope (deferred)

- Patching `cfar_alpha::ALPHA_LIBRARY` to cover the 32-row standard table
  is not done here — Lane G_b is the audit, not the fix.
- The calibrator does not currently model spatial / temporal correlation
  across cells (`ClutterRegime::spatial_correlation` is ignored). The
  alpha library is calibrated under the i.i.d. assumption; the calibrator
  honours that. A follow-up lane could exercise the correlated path.
