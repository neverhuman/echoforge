## Why

The correctness-first v3 plan states that the simulator must reproduce
closed-form textbook radar physics, and that the reproduction must be
*gated* by a permanent test surface rather than ad-hoc review. The
schema-side and validate-side gates already exist (V0/V1/V2/V3 ladder),
but a per-primitive physics-gate at the radar-crate level did not.

This packet lands the **physics validation gate** as a test-only
artefact: every active test checks a closed-form physics relationship
against an existing `echoforge_radar` primitive, and every ignored test
documents (with a `#[ignore]` reason naming the downstream packet that
will unignore it) the closed-form check the upcoming primitive must
pass on day one.

The packet stays inside the test crate boundary by design:
- No source files in `crates/echoforge-radar/src/` are modified.
- `crates/echoforge-radar/Cargo.toml` is unchanged (no new deps;
  active tests rely on the existing public surface plus `std`).
- `FUCKIT.md` is not edited.

## Test list

### Active tests (10) — closed-form checks on existing primitives

1. `rcs_aspect_dependence_present` — same RCS at 0° vs 90° aspect
   differs by ≥ 10 dB for at least one seeded table from
   `Rcs::seeded_public_proxy_v1()`. Confirms the RCS lookup is not
   silently isotropic.
2. `rcs_swerling_0_is_deterministic` — `Rcs::evaluate(...)` with
   `SwerlingModel::Swerling0` returns bit-identical values across
   two calls (Lane B reproducibility).
3. `rcs_swerling_2_pulse_to_pulse_varies` — Swerling 2 fluctuation
   decorrelates pulse-to-pulse (two adjacent pulses differ).
4. `clutter_weibull_shape_2_is_rayleigh` — `sample_weibull(2.0, 1.0,
   seed)` over 5000 trials has mean within 5% of `sqrt(pi)/2 ~= 0.886`
   (Rayleigh expected value for scale=1).
5. `clutter_k_distribution_high_nu_approaches_rayleigh` —
   `sample_k_distribution(20.0, 1.0, seed)` over 5000 trials has
   mean/std ratio within 10% of `sqrt(pi/(4-pi)) ~= 1.913`
   (Rayleigh limit; Ward, Tough & Watts 2013).
6. `clutter_log_normal_mean_of_log` — `sample_log_normal(2.0, 0.5,
   seed)` over 5000 trials has log-mean within 5% of 2.0.
7. `clutter_sample_determinism` — same seed produces bit-identical
   sample for `sample_weibull`, `sample_k_distribution`,
   `sample_log_normal`, and `sample_clutter_amplitude`.
8. `clutter_library_returns_8_regimes` — `ClutterRegime::library()`
   has ≥ 8 entries; each has a representable terrain class, AR(1)
   coefficients in `[0,1]`, finite mean cross-section, and (for
   parametric distributions) positive shape and scale.
9. `ca_cfar_threshold_scale_is_finite_and_positive` —
   `ca_cfar_scale(10, 1e-3)` returns a finite positive scale that
   decreases monotonically when training cells grow from 10 to 32.
10. `rda_cube_shape_consistent` — building a small RDA cube with
    deterministic input produces byte-identical cubes across two
    builds, with the requested `(angle, doppler, range)` shape.

## Notes / Risks / Follow-ups

- **Strict-open posture.** No active or ignored test claims
  platform-specific signature truth, vendor-equivalent performance,
  or operational readiness. All assertions are textbook physics
  checks (Skolnik; Ward, Tough & Watts; ITU-R) against existing or
  future EchoForge primitives. Reference citations live inside the
  ignored test doc-comments so the future primitive lands with the
  reference already paired to the test.
- **`unimplemented!()` is intentional.** Every `#[ignore]` test body
  is `unimplemented!("...")` plus a `// TODO:` block sketching the
  closed-form check. When the downstream packet lands, the
  unignorer flips `#[ignore]` to nothing, replaces the
  `unimplemented!()` with the documented assertion, and the test
  carries its closed-form physics check into the gate.
- **Naming inside doc comments.** TODO comments reference symbols
  like `propagation::two_ray_propagation_factor_magnitude` that
  exist in `crates/echoforge-radar/src/propagation.rs` today but
  are not yet re-exported through `lib.rs`. The `#[ignore]` is
  load-bearing precisely because the symbol is not yet on the
  public surface; the unignorer must wait for the
  `radar-propagation-primitives-v3` packet to expose it.
- **`SwerlingModel::Swerling2` decorrelation tolerance.** The
  Swerling 2 pulse-to-pulse test uses `(p0 - p1).abs() > 1e-9` —
  more than two continuous-distribution draws colliding bit-for-bit
  has probability far below 0.3 percent, so this inequality holds
  with greater than 99.7 percent probability as the packet brief
  required.
- **`clutter_library_returns_8_regimes` is intentionally generous.**
  The active test checks that every `TerrainClass` variant is
  representable in the library and that each entry's parameters are
  physically plausible, rather than pinning specific shape/scale
  numbers. Pinning numbers would couple this test to the choice of
  published source; the packet brief explicitly asks only for
  positive parameters and a non-empty terrain class.
- **`rda_cube_shape_consistent` checks shape and determinism.**
  Per the packet brief, the test asserts the cube has the requested
  `(angle, doppler, range)` shape and that two consecutive builds
  yield byte-identical cubes — the same byte-identical-determinism
  property the `rda_cube.rs` unit tests pin internally.
- **No `FUCKIT.md` edit.** Per packet boundaries, this packet does
  not modify the coordination ledger.
