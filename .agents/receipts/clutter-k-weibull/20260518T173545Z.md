# clutter-k-weibull — heavy-tailed clutter (Weibull / K-distribution / log-normal)

- Timestamp: `20260518T173545Z`
- Packet: `clutter-k-weibull` (Lane G of local coordination scratchpad `20260518T172000Z`
  correctness-first plan)
- Scope: `crates/echoforge-radar/src/clutter.rs` (additive only — no

## Why

`crates/echoforge-radar/src/clutter.rs` shipped scalar correlated
Gaussian noise plus a few glint spikes. Outside reviewers
(`tips/not_real/tip{1..9}.txt`) consistently flag this as physically
wrong: real land/sea clutter at low grazing angles is heavy-tailed.
This packet closes correctness gate **C6** from the
`20260518T172000Z` correctness-first plan by adding the four accepted
amplitude distributions and a published-source-cited regime library,
ADDITIVELY. The existing `ClutterProfile` /
`apply_clutter_to_profile` / `sample_clutter_frame` public API is
byte-stable; legacy callers see no surface change.

The new types are companion APIs intended for downstream Lane A
(radar equation) integration; existing code keeps using the
heuristic profile until callers explicitly opt in.

## Files Changed

- `crates/echoforge-radar/src/clutter.rs` (extended additively;
  pre-edit 173 lines, post-edit 944 lines; +771 lines / +15 tests)
  - Public types (new):
    - `pub enum ClutterDistribution { Rayleigh,
      Weibull { shape, scale }, KDistribution { shape, scale },
      LogNormal { mean_log, std_log } }` — heavy-tailed amplitude
      distributions; cites Skolnik chap. 7 and Ward, Tough & Watts in
      doc string.
    - `pub enum TerrainClass { OpenSky, Desert, Forest, Urban, Sea,
      Mountain, Agricultural, Suburban }` — coarse terrain label used
      to pick a published-source-cited regime; each variant cites its
      shape source in the doc string.
    - `pub struct ClutterRegime { terrain, grazing_angle_deg,
      distribution, spatial_correlation, temporal_correlation,
      mean_power_dbsm_per_m2 }` — fully specified low-grazing
      clutter regime with AR(1) coefficients and `sigma_0` in
      `dB(m^2)/m^2`.
  - Public functions (new):
    - `ClutterRegime::library() -> Vec<ClutterRegime>` — 8 canonical
      regimes (one per `TerrainClass`); shape values cited inline.
    - `ClutterRegime::for_terrain(TerrainClass, f64) -> ClutterRegime`
      — pick a library regime by terrain, override the grazing angle.
    - `sample_weibull(shape, scale, seed) -> f64` — inverse-CDF
      Weibull sampler.
    - `sample_k_distribution(shape, scale, seed) -> f64` — textbook
      texture-times-speckle K-distribution sampler
      (Marsaglia-Tsang Gamma texture × Rayleigh speckle).
    - `sample_log_normal(mean_log, std_log, seed) -> f64` — log of a
      Box-Muller normal.
    - `sample_clutter_amplitude(&ClutterDistribution, seed) -> f64`
      — dispatcher over the enum.
    - `generate_clutter_sequence(&ClutterRegime, n_range_bins,
      n_pulses, seed) -> Vec<f32>` — row-major flat sequence with
      AR(1) across range bins (inner axis) and pulses (outer axis).
  - Private internals (new):
    - `SplitMix64::open_unit_f64` — 53-bit uniform in the open
      interval `(0, 1)` so inverse-CDF transforms never `ln(0)`.
    - `weibull_from_rng`, `standard_normal` (Box-Muller),
      `gamma_marsaglia_tsang` (Marsaglia & Tsang 2000, with the
      `k<1` boost trick), `k_distribution_from_rng`,
      `log_normal_from_rng`, `sample_amplitude_from_rng`.
  - Tests (15 new):
    1. `weibull_shape_two_matches_rayleigh_mean` — Weibull(2,1) mean
       within 5% of the analytic Rayleigh mean `sqrt(pi)/2`.
    2. `weibull_shape_one_matches_exponential_mean` — Weibull(1,1)
       mean within 5% of `1.0` (exponential).
    3. `k_distribution_large_shape_approaches_rayleigh` — at `nu=100`
       the mean/std ratio matches the Rayleigh ratio
       `sqrt(pi/(4-pi))` within 15%.
    4. `log_normal_mean_of_log_matches_mean_log` — `mean(log(X))` is
       within 0.03 of the configured `mean_log=0.5`.
    5. `sample_clutter_amplitude_dispatches_each_variant` — dispatcher
       routes `Rayleigh` to `Weibull(2,1)` and produces finite,
       non-negative samples for every variant.
    6. `same_seed_same_sample_for_each_sampler` — determinism check
       for all four samplers.
    7. `different_seeds_different_sample` — distinct seeds produce
       distinct values for all four samplers.
    8. `clutter_regime_library_has_entries_with_citations` — library
       returns >= 4 regimes covering Rayleigh, Weibull and K-distribution
       families; every regime has AR(1) in `[0,1]` and finite,
       non-positive `sigma_0`.
    9. `for_terrain_sea_returns_k_distribution` — Sea => K-distribution
       (with grazing angle carried verbatim).
    10. `for_terrain_open_sky_returns_rayleigh` — OpenSky => Rayleigh.
    11. `generate_clutter_sequence_returns_expected_length` — returns
        `n_pulses * n_range_bins` samples; degenerate (0, _) and
        (_, 0) cases return an empty vec without panicking.
    12. `generate_clutter_sequence_spatial_correlation_high_when_rho_high`
        — `spatial_correlation = 0.99` on a 4096-bin pulse yields a
        lag-1 sample correlation > 0.8.
    13. `generate_clutter_sequence_is_deterministic_for_same_seed`
        — bit-identical for matched seed; differs for adjacent seed.
    14. The pre-existing `clutter_sampling_is_deterministic_and_finite`
        and `clutter_profile_application_changes_power_deterministically`
        tests are unchanged and still green.

(Tests 1-13 are the 12 enumerated in the packet spec; this packet

## Results / Validation

- All four new samplers are deterministic given a `(seed, params)`
  pair and route through a `SplitMix64` instance owned by the call —
  no `thread_rng` / system-entropy escape hatches.
- The library covers every `TerrainClass` with cited shape
  parameters; `for_terrain` is total over the enum (sound `expect`).
- `generate_clutter_sequence` preserves stationary variance via the
  textbook AR(1) mixing rule
  `x_t = rho * x_{t-1} + sqrt(1 - rho^2) * w_t`
  (Box, Jenkins, Reinsel, "Time Series Analysis", chap. 3).
- Numerical statistical-fit tests run >= 1000 samples and use
  generous tolerances (5-15%) so they pass reliably for the
  PRNG seed family used here.
- No new dependencies; only `std`, `serde`, and the module-local
  `SplitMix64` already present in `clutter.rs`.
- Vendor scrub: 0 banlist matches; no banned strings introduced.

## Citations for shape parameter values in `ClutterRegime::library()`

Verbatim citation strings used in the code's doc comments (with
URLs where available):

- **Skolnik, "Introduction to Radar Systems" 3rd ed. (McGraw-Hill
  2001), chap. 7 ("Clutter").** Source for Weibull-shape values
  for Desert (~1.7), Forest (~1.2), Urban (~0.8), Suburban (~1.0).
  Also discusses K-distribution as the accepted heavy-tailed
  land-clutter amplitude distribution at low grazing.
- **Ward, Tough & Watts, "Sea Clutter: Scattering, the K
  Distribution and Radar Performance", 2nd ed. (IET 2013).**
  Source for the Sea regime (`KDistribution { shape: 8.0, scale: 1.0 }`,
  `sigma_0 ~ -40 dB`); chap. 2 / chap. 3 K-distribution
  tabulations for medium sea state. Also the source of the
  texture-times-speckle product-form K-distribution sampler used
  in `k_distribution_from_rng`.
- **Lin, "A Site-Specific Model of Radar Terrain Backscatter",
  JHU APL Tech Digest, V18 N3 (1997).
  https://www.jhuapl.edu/Content/techdigest/pdf/V18-N03/18-03-Lin.pdf**
  Source for the Agricultural regime (`Weibull { shape: 1.4 }`)
  and corroborating reference for Desert / Forest shape values.
  Also informs the Mountain regime (`KDistribution { shape: 2.0 }`)
  via the heavy-tailed-land-clutter discussion that overlaps
  Skolnik chap. 7.

Marsaglia & Tsang's Gamma sampler ("A Simple Method for Generating
Gamma Variables", ACM TOMS 26(3), 2000) and Box-Muller (1958) are
cited in the relevant private function doc comments; they are
implementation primitives, not regime shape sources.

## Notes / Risks / Follow-ups

- **Strict-open posture.** Every shape parameter in
  `ClutterRegime::library()` is grounded in a published reference
  cited verbatim in the code's doc comments. No shape value was
  invented in this packet, per the local coordination scratchpad `20260518T172000Z`
  correctness-first plan's gate C6.
- **What this unblocks.**
  - **Lane A (radar equation).** The radar-equation work can read
    `mean_power_dbsm_per_m2` straight off a `ClutterRegime` to
    scale amplitude samples into clutter power and combine with
    target RCS and antenna gains. No glue layer needed.
  - **Codex Python v2 mirror.** The four samplers and the regime
    library are pure, deterministic, and source-cited — the Python
    side can mirror them numerically (and verify with the same
    seed-determinism contract) without coordinating on an RNG
    abstraction.
- **Grazing-angle scaling is deliberately not implemented.** The
  packet allows but does not require shape-vs-grazing curves; we do
  not invent one because the literature does not give us a single
  defensible curve. A future packet can add a per-terrain
  grazing-dependence (see e.g. Skolnik chap. 7 figures) with its
  own citations.
- **Existing `ClutterProfile` and friends are byte-stable.** No
  refactor in this packet; the new `ClutterRegime` companion sits
  alongside `ClutterProfile` rather than replacing it. A future
  consolidation packet can decide whether to merge or deprecate.
- **`lib.rs` not touched in this packet.** The radar crate's
  `lib.rs` already re-exports `clutter::{ClutterProfile, ...}` from
  in-flight work prior to this session. Re-exports for the new
  types (e.g. `ClutterDistribution`, `TerrainClass`,
  `ClutterRegime`, `sample_*`, `generate_clutter_sequence`) are
  intentionally NOT added here per the packet's no-touch list; the
  parent agent will add them in a follow-up. The new public items
  are reachable through `echoforge_radar::clutter::*` until that
  re-export lands.
- **No new dependencies.** `Cargo.toml` is untouched. The samplers
  use `std` and the module-private `SplitMix64` only.
- **No existing `ClutterRegime` was found.** A `git grep` for
  `ClutterRegime`, `TerrainClass`, `ClutterDistribution`,
  `sample_weibull`, `sample_k_distribution`, `sample_log_normal`,
  and `generate_clutter_sequence` returned zero hits across the
  workspace before the edit. The pre-existing `ClutterProfile` is
  a fundamentally different shape (per-clutter-source weights),
  and the packet keeps it untouched as required.
