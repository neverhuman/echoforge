## What landed

- New canonical `slow_time_complex_dft(compressed_pulses, n_doppler)`
  that runs an O(N^2) Skolnik-convention slow-time DFT over the per-pulse
  complex IQ, returning a `[range_bin][doppler_bin]` grid of
  `ComplexSample`. Phase is preserved end-to-end, so downstream MTI / MTD /
  micro-Doppler stages can use coherent arithmetic instead of working
  from a magnitude image.
- `slow_time_dft_magnitude` is now a thin wrapper that lifts magnitudes
  into the complex domain (im = 0), dispatches to
  `slow_time_complex_dft`, then collapses to the legacy
  `[doppler][range]` magnitude grid with the 1/N_pulses scaling. The
  wrapper is byte-stable with the pre-Lane-B inlined implementation per
  the new `slow_time_complex_dft_magnitude_matches_legacy` test.
- `SyntheticEpisode` gains `range_doppler_complex: Vec<Vec<ComplexSample>>`,
  populated inside `synthesize_takeoff_episode` from the newly-stored
  compressed complex IQ per pulse. The legacy `range_doppler_proxy`
  field stays in place for back-compat.

1. `sim::tests::slow_time_complex_dft_preserves_phase` — pure complex
   tone `exp(j 2π f_0 n / N)` injected into one range bin produces a
   DFT peak at bin f_0 with magnitude ~N; all other bins are within
   1e-3 of zero.
2. `sim::tests::slow_time_complex_dft_magnitude_matches_legacy` —
   wrapper output matches the inlined pre-Lane-B implementation within

3. `sim::tests::slow_time_complex_dft_handles_empty` — empty pulse

   `synthesize_takeoff_episode` writes a `(compressed_len, pulse_count)`

## Strict-open posture

No measured-truth claims. Phase preservation across the slow-time
Doppler stage is a textbook physics gate; the new tests only assert
closed-form DFT identities and back-compat with the legacy magnitude
grid.

## Notes for downstream

- Lane F (MTI / MTD) consumes `episode.range_doppler_complex` directly.
- Lane H (3-tier detector Tier 3 cruise) uses MTD bins derived from
  `range_doppler_complex`.
- Existing consumers of `episode.range_doppler_proxy` (magnitude grid,
  `[doppler][range]` layout, 1/N-normalised) are unaffected — the
  wrapper is byte-stable.
- `slow_time_complex_dft` is O(N_pulses^2 · N_range). For the takeoff
  fixture (N_pulses = 32, N_range ~ 511) this is ~5 × 10^5 complex
  multiplies per episode — negligible. Callers needing an FFT can wrap
  the public signature without changing the surface.
