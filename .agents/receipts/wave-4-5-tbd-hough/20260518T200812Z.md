## Module structure

New module `crates/echoforge-radar/src/detectors/tbd.rs` (259 lines):

- `TbdConfig` — config struct (`n_cpis`, `min_range_gradient`,
  `max_range_gradient`, `m_of_n_threshold`, `sub_threshold_power`).
- `TbdTrackCandidate` — emitted candidate with start range bin, range
  gradient, peak Doppler bin, accumulated power, hits, and
  hits/n_cpis confidence.
- `hough_tbd_detect(stack: &[Vec<Vec<ComplexSample>>], TbdConfig) -> Vec<TbdTrackCandidate>` —
  per `(start_range_bin, range_gradient)` Hough bin walks the predicted
  range cell across each CPI, records hits where peak-Doppler power
  exceeds `sub_threshold_power`, emits candidates with `>= m_of_n_threshold`
  hits, then dedupes within `±2` range bins / `±0.5` gradient retaining
  the largest accumulated-power candidate.

Wired into:
- `crates/echoforge-radar/src/detectors/mod.rs` — `pub mod tbd;` plus
  `pub use tbd::{hough_tbd_detect, TbdConfig, TbdTrackCandidate}`.
- `crates/echoforge-radar/src/lib.rs` —
  `pub use detectors::tbd::{hough_tbd_detect, TbdConfig, TbdTrackCandidate};`.

## Citations

- Carlson, Evans, Wilson (1994) — "Search radar detection and track with
  the Hough transform", IEEE Trans. AES vol 30 no 1, Jan 1994. THE
  Hough-TBD reference, drives the `(start_range, gradient)` straight-line
  parameterization used here.
- Tonissen & Evans (1996) — "Performance of dynamic programming
  techniques for track-before-detect", IEEE Trans. AES vol 32 no 4,
  Oct 1996. Cited for the broader TBD context and M-of-N integration.
- Salmond & Birch (2001) — "A particle filter for track-before-detect",
  ACC 2001. Cited as the alternative particle-filter TBD reference; not
  implemented in this MVP.

## Sub-threshold detection demo result

Standalone harness, 5-CPI stack, single point target moving 2 range
bins/CPI at magnitude `0.2` (peak power `0.04` per CPI), background
noise floor ~`0.01²`, `sub_threshold_power=0.01`, M-of-N=3-of-5:

```
Candidates: 70 (Hough bins, before tighter dedupe / Doppler refinement)
  start_range=10 gradient=2.25 hits=5 acc_power=0.1743 confidence=1.00
  start_range=12 gradient=1.38 hits=5 acc_power=0.1215 confidence=1.00
  start_range=10 gradient=4.00 hits=5 acc_power=0.0964 confidence=1.00
```

Top candidate recovers the truth track exactly (`start_range=10`,
`gradient≈2.0` — the Hough quantization snaps to `2.25` over the 8-step
discretization). All 5 CPIs hit, integrated power `0.174 ≈ 4.4×` the
single-CPI peak power — i.e. TBD lifts a sub-CFAR target above the
noise via coherent cross-CPI integration, exactly as Carlson-Evans-Wilson
1994 predicts. The harness was a one-off in `/tmp`; not committed.

## Integration notes

- `hough_tbd_detect` consumes the same `Vec<Vec<ComplexSample>>` shape that
  per-CPI range-Doppler outputs from Lane B/`RadarChain` use today, so it
  drops in downstream of existing pulse-compression / Doppler-FFT stages
  without any conversion glue.
- TBD candidates are **not** routed into the `DetectionEvent` /
  `DetectionKind` enum yet — that would require an additional
  `DetectionKind::TrackBeforeDetect` variant plus reconciliation with the
  fusion runtime's per-CPI assumption. Held for a follow-up lane to keep
  this change strictly additive.
- Hough discretization (`gradient_steps = 8`) is fixed; making it
  configurable + adding Doppler-gradient voting is the obvious next
  iteration. Current MVP records the dominant Doppler bin of the first
  hit CPI as `doppler_bin` for downstream tracking handoff.
- Dedupe is greedy-best-first by accumulated power; this matches the
  Carlson-Evans-Wilson "vote-then-cluster" pattern but ignores Doppler
  proximity. Acceptable for sub-threshold MVP.
