# Wave 6 Lane G_c — multi-distribution CFAR ALPHA_LIBRARY expansion

Expands the CFAR `alpha` catalogue from the legacy Gaussian/Rayleigh-only set
to all 8 × 4 = 32 (`ClutterRegime`, `CfarVariant`) tuples of the standard
table, adds four new closed-form `alpha` functions, and seeds the
non-closed-form rows by deterministic 200 k-trial Monte-Carlo calibration
pinned to seed `51805`. The empirical-Pfa post-hoc validator now passes
**32 / 32** rows at 1 M trials per combo (the headline number for this
lane).

## Files Changed | Scope

- `crates/echoforge-radar/src/detectors/cfar_alpha.rs`: new module. Defines
  `ClutterRegime` (8 variants) and `CfarVariant` (4 variants); the
  `AlphaRow` / `AlphaSource` types; closed-form functions for CA-Gaussian
  (Rohling 1983), OS-Gaussian (Rohling 1983 bisection), GO-Gaussian
  (Hansen 1973 / Gandhi-Kassam 1988), SO-Gaussian (Trunk 1978 / Gandhi-Kassam
  1988), Weibull-CA (Watts 1985 / Sekine-Mao power-domain form),
  K-distribution (Wilson-Hilferty / Sangston-Gini 1990), and log-normal
  (Skolnik §7.7.3 median-domain inverse-erfc); the 32-row `ALPHA_LIBRARY`
  table assembled at first access; a `SplitMix64` PRNG, regime sampler, and
  `calibrate_alpha_monte_carlo` for any row without a published closed form;
  the `resolve_alpha` / `resolve_alpha_with_window` dispatcher that prefers
  closed-form, then table lookup, then MC fallback; helper specials
  (`gamma`, `erfc`, `erfc_inv`, `inv_norm_cdf`); and an 11-test in-module
  test suite.
- `crates/echoforge-radar/src/detectors/mod.rs`: re-exports the new module.
- `crates/echoforge-radar/src/lib.rs`: crate-root re-exports for the new
  surface (regimes, variants, closed-forms, dispatcher, helpers).
- `crates/echoforge-radar/Cargo.toml`: adds the `empirical_pfa` example
  target.
- `crates/echoforge-radar/examples/empirical_pfa.rs`: new example /
  post-hoc empirical-Pfa calibrator. Iterates the 32 library rows, draws a
  fresh deterministic Monte-Carlo stream with a verification seed independent
  of the calibration seed, applies the CFAR statistic, and reports
  PASS / FAIL inside a ±50 % band around the target Pfa. Writes one JSONL
  line per row to `outputs/empirical_pfa/<UTC>_post_g_c.jsonl`.
- `crates/echoforge-radar/tests/physics_correctness.rs`: new integration
  test file. Adds the three Wave 6 Lane G_c gates:
  `w6_g_c_alpha_library_covers_full_standard_table`,
  `w6_g_c_closed_form_alpha_ordering_gaussian`, and
  `w6_g_c_closed_form_advertised_for_analytic_tuples`.
- `outputs/empirical_pfa/20260518T203256Z_post_g_c.jsonl`: 32-line JSONL

## Results | Validation

### Closed-form functions added

| Function | Source | Notes |
| --- | --- | --- |
| `ca_cfar_scale_gaussian` | Skolnik §7.7.2; Rohling 1983 | Thin wrapper around the legacy `ca_cfar_scale` for API symmetry. |
| `os_cfar_scale_gaussian` | Rohling 1983 IEEE Trans. AES | Bisection over the Rohling product `Pfa = Π_{i=0}^{k-1} (N-i)/(N-i+α)`. |
| `go_cfar_scale_gaussian` | Hansen 1973 / Gandhi-Kassam 1988 | Bisection on `Pfa_GO(α) = 2·(1+α/M)^{-M} − 2·∑_{k=0}^{M-1} C(M+k-1, k)·(2+α/M)^{-(M+k)}`. |
| `so_cfar_scale_gaussian` | Trunk 1978 / Gandhi-Kassam 1988 | `Pfa_SO(α) = 2·sum(…)` via `f_min = 2f − f_max` identity. |
| `cfar_scale_weibull` | Watts 1985 / Sekine-Mao 1990 (power-domain) | `α = (N·(Pfa^{-1/N} − 1))^{2/c} / Γ(1+2/c)`, reduces to Rohling at c = 2. |
| `cfar_scale_k_distribution` | Wilson-Hilferty / Sangston-Gini 1990 | `α_K = α_Gauss · (1 − 1/(9ν) + z_{Pfa}/√(9ν))^3`, Gaussian limit as ν → ∞. |
| `cfar_scale_log_normal` | Skolnik §7.7.3 | Median-domain inverse-erfc; available as helper, not chosen by the dispatcher because it does not match the arithmetic-mean noise estimator that the library uses. |

## Notes | Risks | Follow-ups

- **Brief deviations.**
  1. The brief asserted "GO ≥ CA, SO ≤ CA" on the alpha multiplier. For
     matched `N = 24` (12 per side vs 24 total) the closed-form derivation
     actually gives the opposite ordering on `alpha` (GO α ≈ 7.09 < CA α ≈
     8.00 < SO α ≈ 10.48) because the per-side max/min estimator biases the
     noise estimate up/down and the multiplier compensates. The composite
     *threshold* (alpha × noise) still orders GO > CA > SO at the operating
     point. The test names were renamed to reflect the alpha ordering
     accurately.
  2. The brief's literal Watts 1985 Weibull formula
     `α = N·(Pfa^{-1/(N·c)} - 1)^c / Γ(1+1/c)` does not reduce to the
     Rayleigh CA form at c = 2; the power-domain Sekine-Mao form
     `α = (N·(Pfa^{-1/N}-1))^{2/c} / Γ(1+2/c)` does, so the gate
     "Weibull(c=2) matches Rayleigh" passes only with the latter. Switched
     formula accordingly.
  3. The brief's literal Watts 1985 K-distribution scaling
     `α_K = α_Gauss · √((Pfa^{-1/ν}-1) / log(1/Pfa))` actually drives the
     ratio to **zero** as ν → ∞ rather than to one. Switched to the
     Wilson-Hilferty cube-root approximation (Sangston-Gini 1990), which
     has the correct Gaussian asymptote.
  4. The Skolnik log-normal closed form keys off a median-domain estimator,
     but the empirical-Pfa harness compares against an arithmetic-mean
     estimator; the closed form is retained as a helper but the dispatcher
     uses MC for log-normal so the row passes the gate.
- **CLI subcommand vs example.** The brief sketched a `cargo run -- calibrate
  empirical-pfa …` invocation. The actual `echoforge-cli` does not (yet)
  carry a `calibrate` subcommand; rather than expand the CLI surface inside
  this lane, the calibrator ships as a `cargo run --example empirical_pfa`
  target under `crates/echoforge-radar/`. The artefact and seed semantics
  are identical; a follow-up lane can promote it to a first-class `ef`
  subcommand.
- **K-distribution and log-normal closed forms are kept available** as
  public functions; the dispatcher's preference order is unchanged for
  future callers who want the analytic value. Only the `ALPHA_LIBRARY`
  table prefers MC for those rows so the gate band holds.
- **No vendor-scrub regression.** The pre-existing `__PLACEHOLDER_*`
  banlist entries continue to fail the gate; this lane adds no banned
  strings.
- **No measured-truth claims.** Every Pfa figure here is synthetic
  Monte-Carlo data drawn from canonical clutter PDFs with deterministic
  seeds; no measured data is referenced.
