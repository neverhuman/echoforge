## Summary

Wires the existing K/Weibull/log-normal `ClutterRegime` primitives
(`crates/echoforge-radar/src/clutter.rs`, Wave A / Lane G) into the
`synthesize_takeoff_episode` synthesis loop so that low-grazing-angle
clutter is heavy-tailed by default whenever a regime is configured on
the `NoiseProfile`. Back-compat is preserved: with
`clutter_regime: None` the loop reproduces the legacy Gaussian AR(1)
sequence byte-for-byte, so existing fixtures and the
`real_world_proxy_v1` profile are unchanged.

## Files Changed

- MOD: crates/echoforge-radar/src/sim.rs
  - `NoiseProfile`: new `clutter_regime: Option<ClutterRegime>` and
    `clutter_sigma_0_scale: f32` fields, both `#[serde(default)]` so
    legacy JSON fixtures still deserialize cleanly.
  - `synthesize_takeoff_episode`: pre-generates a per-pulse
    per-range-bin clutter cube via `generate_clutter_sequence` when a
    regime is configured (preserves the AR(1) spatial+temporal
    correlation that a per-sample dispatcher would lose); otherwise
    falls back to the original Gaussian AR(1) recurrence.
  - Three new inline tests:
    - `noise_profile_default_uses_gaussian_clutter`
    - `noise_profile_with_k_regime_uses_k_distribution`
    - `noise_profile_with_weibull_regime_reproducible`
- MOD: crates/echoforge-radar/tests/physics_correctness.rs
  - Imports extended with `synthesize_takeoff_episode`, `NoiseProfile`,
    `TakeoffProfile`, `EpisodeSeed`, `RadarSimConfig`.
  - New gate: `c6_synthesis_loop_uses_k_regime_when_configured` —
    measures empirical Pearson kurtosis of the IQ real part for a
    K(`nu=0.8`) regime, requires it to exceed 5.0 (Gaussian baseline
    is 3.0).

No re-exports were added in `lib.rs` because `ClutterRegime`,
`ClutterDistribution`, `TerrainClass`, and `generate_clutter_sequence`
are already exposed from Wave A.

## Strict-open posture

No measured-truth or platform-specific signature claims. The
K-distribution and Weibull shape/scale parameters used in tests and
in `ClutterRegime::library()` are cited verbatim to standard radar
handbooks; the Lane C wire-in does not invent new physics.
