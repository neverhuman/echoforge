## Motivation

Ukraine's Sky Fortress acoustic-sensor network (~9,500–14,000 distributed
listening nodes) plus the Zvook system together form the dominant
low-altitude C-UAS cueing layer. Open-source reporting describes the
networks as detecting the distinctive piston-engine acoustic signature
that radar struggles to acquire at low altitude over clutter.
EchoForge previously had no module for acoustic cueing; this packet
adds a Bayesian fusion node that combines a radar track with an
acoustic-bearing observation.

No measured-truth claims on real systems are made; all sensor
parameters and weightings are illustrative.

## Fusion formulas

### Azimuth posterior (Gaussian product, Stone-Streit ch. 4)

```
1/σ_combined² = 1/σ_radar² + 1/σ_acoustic²
μ_combined    = σ_combined² · (μ_radar/σ_radar² + μ_acoustic/σ_acoustic²)
```

### Agreement score

```
σ_pool²     = σ_radar² + σ_acoustic²
agreement   = exp(-(μ_radar - μ_acoustic)² / (2·σ_pool²))
```

### Confidence fusion (log-odds with staleness)

```
staleness        = exp(-|Δt| / 10s)                # 10 s half-life
ℓ_radar          = logit(clamp(P_radar))
ℓ_acoustic_raw   = logit(clamp(source_class_prior))
ℓ_agree_term     = ℓ_acoustic_raw · agreement
ℓ_disagree_term  = -|ℓ_acoustic_raw| · (1 - agreement)
ℓ_fused          = ℓ_radar + staleness · (ℓ_agree_term + ℓ_disagree_term)
P_fused          = sigmoid(ℓ_fused)
```

Key design choice: staleness multiplies the *whole* acoustic
contribution rather than just the raw weight. This makes a stale
observation an uninformative (zero-log-odds) update per Stone-Streit
ch. 7, preventing the clamped-near-zero weight from producing a
spurious large *negative* log-odds.

### Class posterior

```
P(class | radar, acoustic) = P_fused · (1 + source_class_prior) / 2
```

## Measured fusion values

Baseline radar: `range=5000 m, az=100°, σ_az=2°, conf=0.7`.

| Scenario                                                       | conf   | agree  | az (°)   | σ_az (°) | class |
|----------------------------------------------------------------|--------|--------|----------|----------|-------|
| **Agreement** (acoustic 101°, σ=5°, prior=0.8, Δt=0.5 s)       | 0.8929 | 0.9829 | 100.1379 | 1.8570   | 0.8036|
| **Disagreement** (acoustic 120°, σ=5°, prior=0.8, Δt=0.5 s)    | 0.3849 | 0.0010 | 102.7586 | 1.8570   | 0.3464|
| **Stale** (acoustic 101°, σ=5°, prior=0.8, Δt=30 s)            | 0.7138 | 0.9829 | 100.1379 | 1.8570   | 0.6424|

Observations:

* Agreement raises fused conf from 0.7 → 0.89 (≈+27 % relative); the
  gate threshold of >0.85 holds.
* Disagreement drops fused conf from 0.7 → 0.38 (well below the 0.6
  gate threshold) and pulls the posterior mean to 102.76° (toward the
  lower-variance radar).
* Stale acoustic (30 s ≈ 3 half-lives → staleness ≈ 0.05) yields fused
  conf 0.71, only +0.013 above radar baseline — confirms the
  uninformative-update behaviour.
* Posterior σ_az = 1.857° < min(2°, 5°), matching the closed-form
  Gaussian product √(1/(1/4 + 1/25)) ≈ 1.857°.
